BEFORE INSTALL

Prepare

Use this only on an SMK-37 Pro. Do not install it on an Elite or another model.

  1. Keep a way to restore the original SMK-37 Pro firmware.
  2. Close other MIDI programs and connect the keyboard with a data USB cable.
  3. Open this page in Chrome or Edge and leave the cable connected until the install finishes.

Installation replaces the two user sample slots with organ stop waves. If interrupted, reconnect and click Install to continue.
